# Life Theological Seminary - Media Library

## How to use this site

1. **Add the logo**
   - Save the transparent logo as `logo.png`
   - Place it inside the `images/` folder

2. **Add your videos**
   - Put all `.mp4` files inside the `videos/` folder

3. **Add your audios**
   - Put all `.mp3` files inside the `audios/` folder

4. **Link the files**
   - Open `script.js`
   - Edit the `mediaFiles` array at the top
   - Follow the exact format of the examples already there

5. **Test the site**
   - Open `index.html` in your browser
   - Or use VS Code Live Server for best results

6. **Put it online (free)**
   - Go to https://app.netlify.com/drop
   - Drag the entire `school-media-site` folder onto the page
   - You will get a free public link you can share with students

## Folder structure

```
school-media-site/
├── index.html
├── style.css
├── script.js
├── README.md
├── images/
│   └── logo.png          ← put your logo here
├── videos/
│   └── (your .mp4 files)
└── audios/
    └── (your .mp3 files)
```
